# Chatenizer

## Descripción
Aplicación móvil para Android y iOS que convierte conversaciones de correo electrónico en conversaciones de chat con capacidades de IA.

## Objetivo
- Obtener conversaciones desde servicios de correo
- Mostrarlas en formato de chat
- Incorporar capacidades de IA para mejorar la experiencia del usuario

## Tecnologías
- Plataforma: Android e iOS (posiblemente Flutter, React Native u otra tecnología multiplataforma)
- IA: Integración de inteligencia artificial para procesamiento de conversaciones
